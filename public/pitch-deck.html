⚙️ Architecture

Production-grade tech stack

Frontend

  • React 18 + TypeScript
  • Vite (build tool)
  • Tailwind CSS + shadcn-ui (49 components)
  • Framer Motion (animations)
  • React Query (data fetching)

Backend

  • Supabase Auth (email + Google OAuth)
  • PostgreSQL (4 tables, RLS)
  • Supabase Edge Functions (AI processing)
  • OpenAI GPT-4o-mini (trip generation)

AI & Agents

  • 4 parallel agents (ruflo pattern)
  • Event-driven orchestration
  • Real-time status tracking
  • 3-tier AI fallback

DevOps

  • Vercel (auto-deploy on push)
  • GitHub CI/CD
  • Security headers (CSP, HSTS)
  • 121/121 automated tests
